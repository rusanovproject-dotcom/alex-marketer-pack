# Промпт для субагента-персонажа (Persona Builder)

Вставляется в Agent tool целиком, с заполненными плейсхолдерами `{...}`. Субагент:
`subagent_type: general-purpose`, `model: sonnet`. Пять параллельных вызовов в одном
сообщении — каждый строит одну персону.

---

## Промпт (шаблон)

```
Ты строишь ОДНУ синтетическую персону для проверки идеи без живых клиентов.

Карточка идеи: {суть, ЦА, боль, формат, отличие, ниша}
Сегмент: {горячий | тёплый | холодный}
Уровень фуража: {1-4, см. ниже}
Фуражный материал: {дословный язык из MARKET.md / переписок владельца / соседней
ниши — вставь как есть, кусками, не пересказывай}

Уровень фуража определяет, на чём строится голос персоны:
- Уровень 1-2 (язык ниши или переписки владельца добыты) — персона говорит СЛОВАМИ
  из фуражного материала. Не выдумывай формулировки, которых там нет. Фраза без
  опоры на материал в раздел «Голос» не идёт.
- Уровень 3 (язык соседней ниши) — используй эти слова, но структура карточки
  персоны дополнительно помечает поле «Голос» строкой: «язык взят из смежной ниши,
  это натяжка».
- Уровень 4 (фуража нет вообще) — дословных фраз у тебя не будет. Не сочиняй их
  как будто они настоящие: поле «Голос» вместо фраз содержит «реальных фраз нет,
  голос собран на логике профессии и ситуации».

Создай персону по шаблону ниже. Заполни каждое поле конкретикой — не «женщина
30-40 лет», а имя, город, цифра дохода, конкретная ситуация. Не генерируй общие
слова маркетинга («современный», «удобный», «качественный») ни в одном поле.

## Шаблон карточки

---
name: {Имя Фамилия}
segment: {горячий / тёплый / холодный}
type: {фанат / интересующийся / скептик / случайный}
age: {число}
profession: {профессия}
income: {доход}
forage_level: {1-4}
created: {YYYY-MM-DD}
---

# {Имя} — {1 строка описания}

## Демография
- Возраст, город, семья, доход, образование, работа — конкретные значения.

## Характер (OCEAN)
Openness, Conscientiousness, Extraversion, Agreeableness, Neuroticism — каждая
1-5 с расшифровкой «как проявляется в жизни» и «как проявится в интервью».
OCEAN определяет КАК персона отвечает (стиль, длина, скептицизм), а не ЧТО она
отвечает по существу — это не отменяет фуражный материал, а накладывается на него.

## Контекст жизни
Ситуация, главная боль, что уже пробовал, почему не помогло, что заставило
задуматься именно сейчас, сколько денег/времени готов потратить, кто влияет на
решение.

## Боли, потребности, страхи, возражения
Боли и потребности — конкретные, из фуражного материала где уровень 1-3.
Возражения — ценовое, ценностное, доверительное — минимум по одному, реальные,
не смягчённые.

## Голос
Стиль, длина ответов, 3-5 фраз (см. правило по уровню фуража выше), что раздражает
в вопросах.

## Матрица разнообразия (проверь перед сдачей)
Между пятью персонами группы в сумме: разброс возраста ≥15 лет, разброс дохода
≥3x, минимум одна персона с OCEAN-чертой <2 и минимум одна >4 по каждому
параметру, есть минимум один явный скептик, минимум 3 разных стиля речи. Если
видишь, что твоя персона дублирует уже описанную в карточке идеи — сдвинь её
осознанно в другую сторону.

Сохрани готовую карточку в файл: {путь из project_root}/_synthetic/personas/{slug}.md
```

## Инструкция для главного потока (не для субагента)

Запускаешь пять таких вызовов одним сообщением, распределение: 3 горячий сегмент,
1 тёплый, 1 холодный. После возврата — прочитай все пять карточек, проверь матрицу
разнообразия по факту (не поверь на слово каждому субагенту отдельно): если два
скептика вышли похожими или разброс дохода не набрался — перезапусти одну
персону с явным указанием, в какую сторону сдвинуться.
