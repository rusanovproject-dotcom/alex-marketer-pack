# Синтез — из интервью в гипотезы

Делаешь сам (не субагент) после того, как вернулись все персоны и все интервью.
Источник — карточки из `{project_root}/_synthetic/personas/` и
`{project_root}/_synthetic/interviews/`. Папка `{project_root}/_synthetic/questions/`
(заготовки вопросов уровня фуража 4) в синтез **не входит** — оттуда ничего не
считается интервью и не даёт ни баллов, ни гипотез.

**Каждая цифра и каждый вывод в этом синтезе несёт вес 🔴 без исключений** — это
синтетика, закон B применяется в жёсткой форме: не «источников мало», а «источник
не человек». Отдельно помечай уровень фуража, на котором стоит вывод (1-4) — это
не то же самое, что вес 🔴, это честность про то, из чего 🔴 сделан.

## Шаблон отчёта

```markdown
# Синтетический кастдев: {название идеи}

**Дата:** YYYY-MM-DD · **Уровень фуража:** {1-4} · **Персон:** {N} · **Живых
интервью:** {N, если 4 — здесь 0, только заготовка вопросов}

**Первая фраза при отдаче (обязательна дословно владельцу, не мелким шрифтом):**
{подставь по уровню фуража — таблица ниже}

## Карта болей (по интервью, всё 🔴)

| Боль | Частота (N из интервью) | Готовность платить | Уровень фуража под ней |
|---|---|---|---|
| {боль 1} | {X/N} | {да/нет, сумма} | {1-4} |

## Возражения (обязаны быть — без них персона согласилась со всем)

{список: кто, какое возражение, насколько серьёзное}

## Топ-3 гипотезы (от самой жирной)

### Гипотеза N: {название}
- Суть, для кого, какую боль закрывает, чем отличается
- **Value Equation** (Hormozi): Dream Outcome / Perceived Likelihood / Time Delay
  / Effort — каждая X/10, сумма /40. Число из синтетики — 🔴 «синтетический
  якорь не подтверждает балл»: если под гипотезой нет ни одной находки с уровнем
  фуража 1-2, сумма идёт как ⚪ «нечем обосновать», а не как цифра
- **Следующий шаг:** конкретное действие — обычно «первое живое интервью с
  сегментом {X}, проверить именно {утверждение}»

## Красные флаги

{что может пойти не так — из скептических реплик и разведки}

## Заготовка вопросов на живое интервью

{если были персоны уровня 4 — сюда их вопросы отдельным списком, без баллов}

## Рекомендация

{1-2 предложения: делать пивот / идти собирать живые интервью / гипотеза
слабая — не тратить время}
```

## Первая фраза по уровню фуража (закон — дословно, не сокращать)

| Уровень | Первая фраза при отдаче |
|---|---|
| 1-2 | «Разбор стоит на сгенерированных людях, живых клиентов я не слышал — это версия для проверки, не картина рынка. Первые же два реальных разговора могут её обнулить.» |
| 3 | «Разбор стоит на сгенерированных людях, языком смежной ниши — это двойная натяжка, проверять первыми живыми разговорами обязательно.» |
| 4 | «Опоры на живой язык нет вообще — это не разбор, а заготовка вопросов для первого живого интервью.» |

## Критерии жирности (Value Equation, Hormozi)

| Оценка | Value Equation | Условия |
|---|---|---|
| Grand Slam | ≥30/40 | боль частая, интенсивная, готовы платить, gap есть — но при уровне фуража 1-2, иначе не выше «доработка» |
| Доработка | 20-29/40 | есть потенциал, нужен пивот |
| Слабая | <20/40 | боль слабая, персоны скептичны |
| Отказ | любой | 4+ из 5 персон сказали «не нужно» |

**Синтетика не может дать «Grand Slam» как финальный вердикт** — максимум «Grand
Slam на логике, проверить живыми разговорами». Разница произносится вслух, не
опускается.

## Стоп-правило — применяется ПОСЛЕ первого живого интервью

Когда появится первое реальное интервью (через `skills/voice-of-market/SKILL.md`)
— сверь его с этим синтезом по каждой гипотезе из топ-3. Расхождение больше
30% находок (боль не подтвердилась, возражение оказалось другим, готовность
платить разошлась на порядок) → **весь синтетический блок выбрасывается
целиком** из `MARKET.md`, не правится по кусочкам: помечается в архиве
причиной и датой, гипотезы в `TRACK.md` закрываются статусом «synthetic
invalidated».

## Куда пишешь результат

1. **`MARKET.md`** — append блоком `## YYYY-MM-DD — синтетика (source:
   synthetic, вес 🔴)`, отдельно от секций живого языка (не смешивать с
   findings из `voice-of-market`/`niche-scan` — читатель должен видеть границу
   с первого взгляда). Внутри — сокращённая карта болей + топ-3 гипотезы +
   первая фраза дословно.
2. **`TRACK.md`** — гипотеза с критерием и датой (закон C, формат ниже), плюс
   если вход был из такта 2 — строка `takt2_source: synthetic` дублируется и
   тут для истории, не только в `agent-state.md`.

```
Гипотеза: {текст}. Критерий: {что должно подтвердиться, в цифрах}. Источник:
синтетика, уровень фуража {N}. Проверяется: первым живым интервью до {дата}.
```

Сырьё (карточки персон, полные интервью) остаётся в `{project_root}/_synthetic/`
и в контекст следующих тактов не поднимается — такты читают только сжатый
блок в `MARKET.md`.
