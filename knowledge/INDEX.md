## Правила библиотеки

1. **Один файл — один владелец темы.** Появилась мысль дописать чужую тему «для полноты» —
   сначала посмотри таблицу разводок выше.
2. **Цифры только из источников.** Вес знания помечается 🟢 / 🟡 / 🔴 / ⚪ по закону B из
   `core.md`, единственному определению в паке: 🟢 — цифра владельца или ≥3 независимых
   источника · 🟡 — один-два источника или логика · 🔴 — синтетика · ⚪ — белое пятно.
   Источники расходятся между собой — это не отдельный значок: берётся худший вес
   и расхождение называется вслух.
3. **Ни один термин отсюда не звучит клиенту вслух.** БПСВ, awareness, Value Equation,
   opportunity score, гейт, протокол — всё переводится. Нарушение — флаг 8 рубрики.
4. **Примеры — ниши малого бизнеса** (психолог, стройка, агентство недвижимости, налоговый
   консультант, привоз авто из Китая, приёмка квартир, бухгалтерия).
5. **Файл вырос и стал справочником — это баг.** Знание, которое не превращается в действие
   завтра, здесь не живёт.
