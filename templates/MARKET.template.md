**Железное правило файла: без ссылки на источник с автором и датой сюда ничего не
попадает.** «Обычно в этой нише», «по опыту рынка», «принято делать» — не строки этого
файла. Не нашли — пишем ⚪ и говорим об этом вслух.

**Второе железное правило — дословная цитата.** Ссылки мало: рядом с каждым источником стоит
**дословный кусок 10-25 слов с той самой страницы**, скопированный, а не пересказанный. Цитата —
единственное доказательство, что страницу открывали, а не сочинили правдоподобный адрес.
**Строка без цитаты — не источник: вес ⚪, в выводы не идёт.** Страница открылась, а нужного
куска на ней нет — так и пишем в цитате: «на странице этого нет», и вес ⚪.

## Как в нише доводят до оплаты

| # | Схема одной фразой | Кому годится | Вес | Источник (автор, дата, ссылка) | Дословно со страницы (10-25 слов) |
|---|---|---|---|---|---|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

**Правило неразрывной строки: вывод пишется вместе со своим условием, в одной строке.**
Не «продают без разговора», а «продают без разговора **с автором** — дальше клиента ведёт
куратор». Условие отваливается первым: оно остаётся в подробном разборе, а в следующий шаг
маршрута уезжает голый вывод, и на нём строится гипотеза. Проверено на боевом прогоне —
между разведкой и проверкой из фразы пропали два слова, и на обрезанной версии встал
эксперимент на месяц. Кто берёт отсюда строку — цитирует её целиком, а не пересказывает.

**Вывод не бывает шире источника.** Перед тем как записать находку, спроси, чего источник
**не** говорит: у механики почти всегда есть условие применимости, и оно едет вместе с ней.

**Правило веса:** источник продаёт обучение или услугу по той самой механике, которую
описывает, — потолок 🟡, сколько бы таких ни было. 🟢 требует одновременно ≥3 независимых
стороны **и** хотя бы одного практика с собственным кейсом в цифрах. Перенос механики с
другого рынка — всегда 🟡, «работает там, у нас не проверено».

## Как дописывать

```
## YYYY-MM-DD — что изменилось
- <находка одной строкой ВМЕСТЕ с условием, при котором она верна> · вес <🟢/🟡/🔴/⚪> · источник: <автор, дата, ссылка>
  дословно: «<10-25 слов с той страницы>»   ← нет цитаты, значит нет источника: вес ⚪
```

Смоделированные реплики дописываются **отдельным блоком с пометкой 🔴** и
никогда не подмешиваются в секцию дословного языка рынка.

Сырьё разведки (транскрипты, выгрузки) живёт в `_raw/` рядом и сюда не переносится —
здесь только выжимка и ссылка.

**Лимит 300 строк.** Перевалил — сворачивает тот, кто этим файлом владеет (см. служебную пометку вверху);
зашёл другой и увидел перевал — сворачивает сам и пишет об этом строкой. Старые блоки уходят в
`_archive/MARKET-<дата>.md` рядом, **на месте свёрнутого блока остаётся строка-ссылка с датой и
сутью** («2026-06-02 — разведка воронок ниши, 3 схемы → `_archive/MARKET-2026-06.md`»).
