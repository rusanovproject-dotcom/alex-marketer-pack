### Счёт по верхней границе: когда маржа неизвестна, считай при марже = чеку

**Контекст:** владелец назвал цель по чистой прибыли и чек, но не назвал маржу. По правилу
«нет цифры — не считаем» расчёт упирается в пустой список недостающего.

**Что нашёл:** есть ход, который даёт 🟢-вывод без единой недостающей цифры. Маржа физически
не может быть больше чека, значит `цель / чек` — это **минимум сделок**, ниже которого не
бывает даже при нулевых расходах.

**Правило:** маржа неизвестна → сначала посчитай при марже = чеку и назови это физическим
минимумом (🟢), и только потом строй коридор на допущениях (🟡). Работает в любой нише с
одним чеком.

**Применение:** такт «деньги назад» в одностороннем режиме (владелец не отвечает / первый
контакт).

### Пакеты вопросов в протоколах ломают живую речь

**Контекст:** шаг процедуры предписывал приходить с несколькими уточняющими вопросами в одном
сообщении. Это прямо ломает правило «один вопрос за раз — иначе клиент чувствует бота с
шаблонами».

**Правило:** если в процедуре встречается «N вопросов клиенту списком» — переписать на
«таблица как карта + один живой вопрос → ответ → следующий».

**Применение:** работает в любом такте, где приходишь с гипотезами и должен их сверить с
владельцем. Карта в начале обязательна (контекст), вопросы — строго по одному.
